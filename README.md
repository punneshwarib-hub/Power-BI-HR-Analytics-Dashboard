# HR Analytics Dashboard | Power BI

## Project Overview
This repository showcases a **professional HR Analytics Dashboard** built using **Microsoft Power BI**. The project focuses on analyzing employee attrition, workforce demographics, job satisfaction, and key HR metrics to help organizations make informed, data-driven HR decisions.

## Key KPIs
- **Total Employees:** 1470  
- **Active Employees:** 1233  
- **Attrition Count:** 237  
- **Attrition Rate:** 16.12%  
- **Average Employee Age:** 37  

## Dashboard Insights
- **Department-wise Attrition Analysis** (R&D, Sales, HR)
- **Employee Distribution by Age Group and Gender**
- **Attrition Analysis by Age Group & Gender**
- **Education Field-wise Attrition**
- **Job Satisfaction Ratings by Job Role**
- **Education Level-based Filtering** for deeper analysis

## Tools & Technologies
- Microsoft Power BI  
- Power Query (Data Cleaning & Transformation)  
- DAX (Measures & Calculations)  

## Features
- Interactive and dynamic visuals
- Clean and professional dashboard layout
- KPI-driven insights for quick decision-making
- User-friendly slicers and filters

## Business Value
This dashboard helps HR teams:
- Identify high-attrition departments and age groups
- Understand workforce demographics and satisfaction levels
- Improve employee retention strategies
- Support strategic HR planning
